Cargar cupones

Esta página es para quien administra el sitio. No hace falta saber de informática.

Cómo se hace

  1. Completá los datos del cupón y tocá Agregar a la lista.
  2. Revisá que más abajo diga Todo en orden.
  3. Tocá Copiar todo el texto.
  4. Tocá Abrir el archivo en GitHub (iniciá sesión si te lo pide). Tocá el lápiz para editar, seleccioná todo el texto que hay, pegá el nuevo y tocá Commit changes y, en la ventana que se abre, de nuevo Commit changes.
  5. Esperá unos minutos y revisá el sitio.

Si algo sale mal, no pasa nada: el sitio sigue funcionando y podés volver a intentarlo.
